# Лабораторная работа №4

Ким Максим Сергеевич, группа 221341, вариант 7, лабораторная №4.

Функциональное программирование на Python 3.13: декораторы,
генераторы, `reduce` и собственные классы-итераторы. Только
стандартная библиотека.

## Задания варианта

**Средняя сложность:**

- №7 — декоратор для логирования вызова функции
  (`lab4/logging_decorator.py`)
- №9 — генератор случайных чисел в диапазоне
  (`lab4/random_range.py`)
- №3 — сумма чисел через `reduce` (`lab4/sums.py`)

**Повышенная сложность:**

- №7 — бесконечный генератор случайных данных
  (`lab4/infinite_stream.py`)
- №5 — собственный класс-итератор (`lab4/iterator_class.py`)

## Клонирование

```bash
git clone https://github.com/maxonchik17569/mtp-lab4-variant7.git
cd mtp-lab4-variant7
```

## Запуск

```bash
uv run python -m lab4
```

Демонстрация печатает по разделу на каждое задание и показывает
логи декоратора, воспроизводимость seed, граничные случаи и
работу итератора.

## Проверки

```bash
uv run python -m unittest discover -s tests -v
uv run --with flake8 flake8 lab4 tests
uv run python -m compileall -q lab4 tests
```

Подробное описание выполнения, принятых решений и результаты
